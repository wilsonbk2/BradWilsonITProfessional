QAPI Centralized Database Launch Process

  • This is a very simple but yet clever application launch process to incorporate my intital splash screen, and set registry preferences and run updates all at the same time.
  • The process starts out with an old file type ".hta" and this is to actually is what is used to run my gif splash screen and then sneakily runs the vbs script to run my BAT invisible.
  • The main BAT files determines if the program needs to be installed on the users computer first, and installs if not and updates new version if it is. Next it sets two registry files to ensure the program works correctly with network group policy and runs smoothly, then runs the programs after initializing processes are comkplete.

QAPI Enterprise Database VBA Code Base

  • The code base below displays many different functions and form coding blocks that allowed the app to run smoothly, efficiently, and securely.
  • Being that this frontend was written in VBA/VBS scripting it was limited in places but very robust on a local desktop interface.
  • Being that this database interfaced with access databases I was tasked to secure it as much as possible given Access's very unsecure nature. There were many different methods I used to hunker down this application's security including UI table manipluation, right click menu limits, vbaAllowBypassKey handling, deep password encryption, enforcing user security protocols, network security group permissions. All of these together made the database almost impenetrable by that time periods standards.
  • You can view some examples of this database on the QAPI portfolio item which you can Click here to visit
  • One thing that comes along with anything asscoiated with access databases is the dreaded locked databse file. This was a headache for original database I worked on before I deleveloped this one specifically myself. So when engineering this database I baked in a user kick-out protocol that when the database needed maintenance I could click a button and forcefully kick all users out of the database to unlock the files being locked. And of course I gave them time to finish their current work! :)
  • Since this was my first ever enterprise application I created I was super passionate about it, and I actually baked in a hidden game into the application.
