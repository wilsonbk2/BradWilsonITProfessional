The Power BI Effect

The Power BI Effect began in 2018 when the hospital CEO selected me to lead an initiative to transform how data was collected, analyzed, and used for decision-making. I developed the data infrastructure needed to funnel large-scale operational data into Power BI, giving executive leadership unprecedented visibility into departmental performance. The project has since expanded into 8+ dynamic dashboards covering critical areas across the facility.

Employee Staffing Event Dashboard

  • This dashboard showcases the depth of detail I was able to architect into the database schema and ability to showcase that minute fine detail into the visualization itself from beginning of the SDLC.
  • It displays thousands of records at one time and the ability to finely tune it down to exactly which trend to identify current issues and how, when, where, and why they happen.
  • The dashboard is linked to a live database feed of data entered regarding employee events and related to the specified employee ID. Which allows the user to identify individual trends a lot easier.

Facility Code Safety Events

  • This dashboard is farily similar to the last, but is regarding critical emergency events across an organization. It identifies the time and place of events and the trends from implementation of corrective measures.
  • This dashboard was actually used to predict patient behavior, and proved itself very reliable when identfying the units and the time the events usually occur. Which allowed intervention to decrease critical events over time.
  • Quick fact: This data and dashboard itself was utilized in a scientific PhD peer-reviewed journal that was later publicly published and does include my name for my contributions.

Staffing Employment Levels Predictive Modeling

  • This dashboard showcases the usage of predictive analytics utilizing big data to get the most accurate and possible outcome. It features a complex DAX algorithm based code to map out employees staffing levels on each and everyday of the year over time.
  • As you can see from the visual to your right, you can open up a filter box narrow down your results to any and everytype of employee position, and their retention over the course of time.
  • And how you can manipulate the preditive trend for your data set.

Daily Patient Census Historical Trend Analysis

  • This dashboard probably tells the biggest story of them all, because there are such drastic data points that specifically point to events over time and what actually happened to cause these shifts over time.
  • This was used to monitor the patient population over time and how many patients we had on a given day.
  • It was later combined with the staffing levels metric graph to calculate an employee to patient ratio for hospital safety protocols.

Daily Patient Census By Patient Type

  • With this dashboard it is very similiar to the last but it breaks down the patient population into the different types of patients at a given time over the course of history, and displays which ones have increased or decreased.
  • It also displays many filters to really fine tune the data so the user can actually find what they need and depict real world solutions from the trends themselves.

Admission & Discharge Status & Demographics

  • This dahsboard displays patient admission and discharges over time, and the demographics associated with them. As well as the amount of time the patients tend to spend at the hospital with a given trend graph to watch tis trend.
  • It also features many dynamic filter visualizations that allow the user to view the data in so many different ways that most users didn't even know was possible.
  • The calculations of all of the metrics and number variations within all the visualizations were carefully vetted and justified from licensed clinical executives ensuring legitment output.

Power BI Dynamic Relationships

  • This is not a dashboard; however it does show case the dataset relationships behind all of the visualizations being showcased above.
  • All of these datasets are predefined with SQL and formatted carefully to relate correctly within the Power BI application to ensure that all of the dynamic datasets visualizations move together as one unit, allowing the user to see multiple large "Big Data" data sets compared across a couple visuals that really paint a picture that essentially was not conceivable before their creation.
